# Sard: 와이어 스피드 PCAP 포렌식 & JA4 TLS 핑거프린팅 데몬

[English](README.md) · [라이선스](LICENSE)

Sard는 순수 Go 표준 라이브러리만으로 구현된 제로 힙 할당 TLS 세션 분석기, JA4 네트워크 핑거프린팅 엔진 및 포렌식 데몬입니다. 외부 의존성 없이 대용량 패킷 캡처(PCAP/PCAPNG) 파일과 실시간 네트워크 스트림을 파싱하여 클라이언트 암호화 핑거프린트를 추출하고, 패킷 도착 지터 계산, DGA 섀넌 엔트로피 평가를 통해 이상 징후 및 악성 트래픽을 식별합니다.

## 듀얼 운영 프로시저

### 1. 고속 와이어 스트리밍 모드 (`--mode=fast`)
- 회선 속도(Line-rate) 패킷 수집, 실시간 침입 탐지 시스템(IDS) 피드, 임베디드 패킷 탭 장비에 최적화.
- 상태 캐시를 건너뛰고 제로 힙 메모리 할당으로 TLS ClientHello 핑거프린트를 즉시 추출.
- 코어당 초당 5,000,000 패킷 이상의 처리량과 16MB 미만의 극소 메모리 점유율 유지.

### 2. 정밀 포렌식 & 위협 분석 모드 (`--mode=deep`)
- 침해사고 대응(IR), 악성코드 트래픽 분석(MTA), 보안관제센터(SOC) 텔레메트리에 최적화.
- 5-튜플 TCP 세션을 재조합하고, 패킷 도착 지터를 계산하며, SNI 호스트명의 슬라이딩 윈도우 섀넌 엔트로피를 측정하여 생성 알고리즘(DGA) 도메인을 탐지.
- SNI 없는 직접 IP 접속, 비정상 소수 암호 스위트 열거 등의 위협 행위를 점수화하여 플래그.

## 설치 및 빌드

```bash
git clone https://github.com/Aetherx86/Sard.git
cd Sard
go build -o bin/sard ./cmd/sard
```

## CLI 사용법

```bash
# 기본 고속 스트리밍 모드로 PCAP 분석
./bin/sard -r capture.pcap

# 구조화된 NDJSON 출력과 정밀 상태 기반 포렌식 분석
./bin/sard -r capture.pcap --mode=deep --json

# 특정 SNI 도메인 필터링
./bin/sard -r capture.pcap -filter-sni="internal.vault"

# 위협 점수가 감지된 이상 플로우만 경보 출력
./bin/sard -r capture.pcap --mode=deep --alert
```
